# Five-Tier Faction Mapping Baseline

This document maps existing and planned units and structures to the five-tier model.

## Tier Model

- T0: Opening economy, scouting, and baseline combat enablement.
- T1: First tactical specialization and map-control tools.
- T2: Midgame power spikes and role-deepening options.
- T3: Late-game strategic systems and theater-wide pressure.
- T4: Apex systems that reshape map control and endgame tempo.

## Named Factions

- American Expeditionary Command
- Chinese Systems Front
- Frontier Covenant
- Veyari Ascendancy
- Promethean Assembly
