# itch.io Stage 0 Publish Runbook

This runbook converts Stage 0 publication into a deterministic operator procedure.

## Scope

- Stage 0 Coming Soon page publication only.
- No downloadable build required.
- Uses copy from planning/itch-io-launch-and-feedback-plan.md and media from planning/stage0-media-bundle-spec.md.

## Inputs Required

- Final Stage 0 page copy block.
- 3 to 6 screenshots and optional 0 to 2 clips.
- Gameplay-first captions.
- Pre-Alpha transparency statement.

## Preflight Checklist

- [ ] Page copy selected from approved draft.
- [ ] Media package meets Stage 0 media specification.
- [ ] Captions validated against current implemented scope.
- [ ] Known-gaps section reviewed for accuracy.
- [ ] Follow CTA and feedback instruction block included.

## Publish Procedure

1. Open itch.io dashboard and create or open project draft page.
2. Set page status and visibility to Coming Soon mode.
3. Paste hero, about, feature bullets, trust section, and feedback CTA.
4. Upload screenshots in prescribed sequence S0-01 through S0-06 where available.
5. Add caption text matching media order.
6. Apply transparent build status label: Pre-Alpha.
7. Confirm no download upload is exposed for Stage 0.
8. Save draft and run final copy and media review.
9. Publish page.
10. Post first update entry linking feedback expectations and next milestone window.

## Post-Publish Validation

- [ ] Public page loads with all media visible.
- [ ] Follow CTA is present and readable.
- [ ] Pre-Alpha label is visible above fold.
- [ ] Feature bullets match implemented or near-term scope.
- [ ] No broken image or clip links.
- [ ] First update post is published.

## Evidence Capture for Trackers

After manual publish, record the following into tracking files:

- Publication timestamp.
- Public page URL.
- Media count and clip count.
- Confirmation of first update post.
- Any deviations from runbook.

## Manual External Step

- Actual page publication and verification must be performed in the itch.io web interface.
