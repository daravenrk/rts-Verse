# Ideology Paths Baseline

This document defines first-pass ideology paths for midgame and late-game strategic divergence.

## Scope

- Shared progression context: players begin in common survival-opening conditions.
- Ideology divergence starts during Augmented Warfare and compounds through Autonomous and Network phases.
- This pass defines strengths, liabilities, and failure modes for each path.

## Path A: Purists

### Identity

Human-centric doctrine that preserves biological command authority and disciplined industrial expansion.

### Core Strengths

- Reliable opening and midgame tempo with lower systems volatility.
- Strong logistics consistency under contested map pressure.
- Better recovery from partial network disruption because doctrine avoids over-automation coupling.

### Core Liabilities

- Lower peak throughput than automation-heavy paths in long matches.
- Slower adaptation when rapidly changing fronts require high dynamic rerouting.
- Greater dependence on intact civilian throughput for sustained strategic scaling.

### Failure Modes

- Attritional lock-in: overcommitting to stable lines can lose initiative against high-mobility branches.
- Under-scaling risk: failure to secure second and third economic zones causes late-game capability deficit.
- Doctrine rigidity: delayed branch pivots can produce irreversible tempo loss.

## Path B: Symbiotes

### Identity

Hybrid doctrine that blends human command structures with alien-adaptive systems and ecological integration.

### Core Strengths

- Strong adaptation to map-state swings and mixed-theater pressure.
- High objective-contest resilience through flexible role reassignment.
- Efficient transition windows when branch decisions are timed around contested resource cycles.

### Core Liabilities

- Requires higher execution precision to realize full value.
- Vulnerable to disruption during active adaptation windows.
- Can suffer uneven output if branch synergies are unlocked in the wrong order.

### Failure Modes

- Adaptation cascade stall: one failed transition window delays subsequent branch power spikes.
- Split-focus collapse: overextending hybrid tools across too many fronts lowers decisive pressure.
- Counter-readability exposure: predictable adaptation patterns can be pre-countered by prepared opponents.

## Path C: Cybernetic Ascendants

### Identity

Machine-forward doctrine emphasizing automation scale, distributed command, and high-intensity network warfare.

### Core Strengths

- Highest late-game operational throughput when systems remain synchronized.
- Strong disruption potential through network-level pressure tools.
- Scales effectively with relay and shard infrastructure investment.

### Core Liabilities

- High maintenance burden in bandwidth, cooling, and logistics stability.
- Acute vulnerability to cascading failures when network nodes are disrupted.
- Opening and early-midgame can feel brittle if macro setup is rushed.

### Failure Modes

- Network cascade: relay failures propagate command penalties faster than recovery can compensate.
- Maintenance insolvency: automation expansion exceeds upkeep envelope and collapses production cadence.
- Core isolation: insufficient distributed fallback causes severe penalties after key-node loss.

## Cross-Path Balance Guardrails

- Each ideology must provide a unique win condition profile without deterministic matchup outcomes.
- No ideology may bypass shared stockpile, depletion, or event-volatility constraints.
- Counterplay windows must remain visible before each path reaches peak scaling state.
- Branch clarity must be readable in HUD and telemetry without requiring out-of-game references.

- Flow F-12: era transition readability must expose branch unlock timing and trigger reason.
- Flow F-15: dynamic branch emergence must demonstrate distinct strengths and liabilities for all three ideologies.
